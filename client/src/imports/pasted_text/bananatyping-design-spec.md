# Техническое задание на дизайн главной страницы «BananaTyping»

**Цель:** Создать интерактивный макет главной страницы тренажера слепой печати в Figma с использованием Auto Layout и подготовленной дизайн-системой (UI Kit).

## 1. Глобальные стили (Design Tokens)

* **Цвета:**
* `Primary Yellow`: Насыщенный желтый (напр., `#FFD700` или `#FACC15`). Используется для кнопок, акцентов, подсветки текста.
* `Dark / Surface Inverted`: Черный или темно-графитовый (напр., `#111111`). Фон для Hero-блока и футера, цвет текста на желтых кнопках.
* `Background`: Белый `#FFFFFF` и светло-серый (напр., `#F8F9FA` для фона страницы под карточками).
* `Text Primary`: Черный/Темно-серый для заголовков и основного текста на светлом фоне.
* `Text Secondary`: Серый для вспомогательного текста (напр., «21 мин»).


* **Типографика:**
* Современный гротеск (без засечек), например *Inter, Roboto, Montserrat* или *GolOS Text*.
* `H1` (Hero): Крупный, жирный, часть слов выделена желтым.
* `H2/H3`: Для заголовков карточек («Лидеры дня», «Ваш прогресс»).
* `Body`: Читабельный текст для набираемого текста в тренажере.


* **Скругления (Border Radius):**
* Глобальное скругление для карточек, кнопок и инпутов: `16px` – `24px` (мягкий, дружелюбный стиль).



## 2. Библиотека компонентов (UI Kit)

Перед сборкой страницы в Figma необходимо создать следующие Master Components:

* **Кнопки (Buttons):**
* `Primary`: Желтый фон, черный текст, скругленные углы. Состояния: Default, Hover, Pressed.
* `Ghost / Text`: Прозрачный фон, подчеркивание при наведении (для навигации).


* **Карточки (Cards):**
* Белый фон, легкая тень (Drop Shadow: Y=4, Blur=10, Opacity=5%).


* **Виртуальная клавиатура (Keyboard Component):**
* Кнопка клавиатуры: светло-серый фон, темно-серый текст.
* Состояния кнопки: *Default*, *Active* (желтый фон при нажатии нужной клавиши), *Error* (красный фон при ошибке).
* Ряды клавиатуры собираются через Auto Layout (горизонтальное направление, фиксированный gap).


* **Иконки (Icons):** Стилизованные минималистичные иконки (ракеты, книги, соцсети) + аватарки пользователей.

## 3. Структура макета (По блокам сверху вниз)

### Блок 1: Header (Шапка)

* **Левая часть:** Логотип (Иконка связки бананов на клавиатуре + текст «BananaTyping» жирным шрифтом).
* **Центр:** Навигация (Уроки, Тесты, Рейтинг, Блог, Профиль). Выпадающее меню у Профиля (иконка стрелочки).
* **Правая часть:** Кнопка Primary «ВОЙТИ / РЕГИСТРАЦИЯ» (вытянутая форма, как таблетка).
* *Техническое требование:* Сделать через горизонтальный Auto Layout, выравнивание `Space between`.

### Блок 2: Hero-секция (Левая часть)

* **Фон:** Темный плашка со скруглением в нижнем правом углу (или сложной волнистой формой).
* **Контент:**
* Заголовок H1: «ОСВОЙ СКОРОПЕЧАТАНИЕ С BANANATYPING!». Слово «BANANATYPING!» должно быть акцентного желтого цвета.
* Подзаголовок: Текст среднего размера белым цветом («Учись печатать быстро...»).
* CTA-кнопка: Желтая «НАЧАТЬ ТРЕНИРОВКУ».


* **Иллюстрация:** Векторный персонаж (парень за клавиатурой) и декоративные элементы (бананы). Выступает за пределы темного фона.

### Блок 3: Зона тренажера и виджетов (Правая часть)

Состоит из трех белых карточек:

1. **Основной тренажер (Центр):**
* **Header карточки:** Статистика в реальном времени (Скорость: 75 СЛ/МИН, Точность: 99%, Время: 0:48). Разделены серыми вертикальными линиями или отступами.
* **Текстовое поле:** Крупный текст. Текущее слово выделено желтым маркером/фоном, активная буква имеет курсор.
* **Клавиатура:** Раскладка (QWERTY/ЙЦУКЕН), где подсвечиваются клавиши текущего и следующего нажатия.


2. **Виджет прогресса (Правый верхний угол):**
* Заголовок: «ВАШ ПРОГРЕСС».
* График: Area Chart (линейный график с желтой заливкой под линией). Оси X и Y светлым цветом.


3. **Виджет лидеров (Под графиком):**
* Заголовок: «ЛИДЕРЫ ДНЯ».
* Список: Место (1, 2, 3), Аватарка (круг), Никнейм, Результат (WPM). Второе место выделить иконкой короны.



### Блок 4: Карточки курсов (Под Hero-секцией)

* Горизонтальный скролл или сетка из карточек.
* **Элементы карточки:**
* Иконка (желтый или черный квадрат со скругленными углами и вектором внутри).
* Название («Курс для начинающих», «Продвинутый уровень»).
* Краткое описание.
* Футер карточки: Иконка книги + кол-во уроков, Иконка часов + время. Иконка стрелки (переход) в правом нижнем углу.



### Блок 5: Footer (Подвал)

* **Фон:** Темный графитовый или черный. Волнистая линия или плавный переход от белого фона вверху.
* **Контент:**
* Логотип (светлая версия).
* Столбцы с навигацией (Ссылки мелким светлым шрифтом).
* Иконки соцсетей (в кружочках).
* Копирайт «2023 BananaTyping © Все права защищены».



---

**Рекомендации для дизайнера:**
Используй фреймворки сеток (например, 12-колоночную сетку шириной 1440px). Все повторяющиеся элементы (строки таблицы лидеров, карточки курсов, клавиши) обязательно оборачивай в Auto Layout, чтобы при передаче макета в разработку можно было легко снять параметры `gap`, `padding` и `margin` для CSS (Flexbox/Grid).
